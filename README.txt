Video Saver — Mac 用試作アプリ

できること
1. 動画 URL を MP4（H.264 / AAC）で保存する（yt-dlp + ffmpeg）。
2. Mac で再生中の音声だけを録音して m4a（AAC）で保存する（ScreenCaptureKit）。
3. アプリ内ブラウザで流し見しながら、録りたい場面から録画・録音する（「ライブ録画」タブ）。

動画の保存
  Video Saver.app を開き、動画 URL と保存先、画質の上限を選んで「動画を保存」を押します。
  初期の保存先は「ダウンロード」です。プレイリストは一括保存しません。
  同名ファイルがある場合は連番を付け、上書きしません。
  対応済みの映像・音声は再圧縮せず、必要なトラックだけ ffmpeg で変換します。
  この Mac に導入済みの ffmpeg / ffprobe を使います（brew install ffmpeg deno）。
  DRM（Widevine 等）で保護された配信、NHK ONE には対応していません。
  保存が認められている動画にお使いください。

音声の録音
  「音声を録音」で、録音する音（Mac 全体 / 選んだアプリ）とタイトル（任意）を決め、「録音開始」を押します。
  ファイル名は「タイトル.m4a」です（同名があるときだけ「タイトル (2).m4a」。タイトルが空なら「録音 日時.m4a」）。タイトルは m4a の曲名にも設定します。
  録音中は画面と Mac が自動でスリープしません（スリープすると取得が止まるため）。
  蓋を閉じる等の手動スリープでは止まります。
  再生された音を録るだけで、配信の保護には触れません。私的利用の範囲で、配信元の規約も確認してください。
  初回は「システム設定 > プライバシーとセキュリティ > 画面収録とシステムオーディオ録音」で許可が必要です。

ライブ録画（「ライブ録画」タブ）
  アプリ内ブラウザでページを開きます（「ラジコ」「YouTube」ボタンで移動できます）。モードは3つです。
  動画 / 音声のみ: YouTube のライブなど。押した時点の配信を yt-dlp で取得し、停止後に MP4 / m4a にまとめます。
    画面を録るのではなく配信データを保存するので、画質は配信そのままです。ラジコには使えません。
  再生音を録音: このアプリ内ブラウザで再生している音だけを録り、m4a で保存します（ラジコ向け）。
    ラジコのページを開くと、番組名と日付からタイトル（「番組名 2026-11-17」）、局名からアーティスト情報を自動で入れます。
    再生は自分で行います。エリア外の局はラジコプレミアムのログインが必要です。初回はアンケートに答える必要があります。

ビルド
  zsh build.sh
  yt-dlp の実行ファイルをこのフォルダ直下に、ffmpeg と ffprobe を tools/ に置いてください（どちらも git 管理外）。
  ffmpeg / ffprobe はアプリ内に同梱します（無ければ Homebrew のものを使います）。
  YouTube の取得に JS ランタイムが必要なため、node 22 以上をアプリ内に同梱します（NODE_BIN で指定できます）。
  署名は「VideoSaver Local Signing」という自己署名証明書（キーチェーンアクセスの証明書アシスタントで
  種類「コード署名」を作成）を使います。無いと ad-hoc 署名になり、作り直すたびに画面収録の許可が外れます。
  配布用の公証はしていません。
