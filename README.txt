Video Saver — Mac 用試作アプリ

ソース整理版（2026-10-11）
構成、現在の到達点、未対応範囲、ビルド・テスト方法は SOURCE_INDEX.txt を参照してください。
NHK番組のMP4保存は未実装です。該当箇所には説明コメントと早期returnを残しています。
ソース一式のZIPには、ログイン情報、動画、CDM等の実行ファイルを含めません。
既存の実験資料は、その実施時点の結果として保存しています。

Video Saver.app を開き、動画 URL と保存先、画質の上限を選んで「動画を保存」を押してください。
初期の保存先は「ダウンロード」です。プレイリストは一括保存しません。
同名ファイルがある場合は連番を付け、上書きしません。
保存と変換には保存先フォルダ内の一時領域を使い、通常の完了・停止・失敗時に片付けます。
強制終了した場合は .video-saver- で始まる一時フォルダが残る場合があります。

この Mac に導入済みの ffmpeg を使います。別の Mac では Homebrew で
brew install ffmpeg deno
を実行するなどして依存ソフトを用意してください。
YouTube の取得には対応した JavaScript ランタイムが必要になる場合があります。

NHK ONE にはアプリ専用のログイン画面を追加しました（macOS 14以降）。
「ログイン画面を開く」からNHKのページでログインしてください。
macOS標準WebKitとアプリ専用の保存領域を使い、TunePat・Chromeの情報を読みません。
「このアプリのログイン情報を確認しました」は、Cookieと期限のローカル確認です。
サーバーでの認証成功や、番組を保存できることを示す表示ではありません。
「このアプリのログインを消去」は、このアプリのWebサイト保存データのみを消去します。
ログイン画面での番組再生とNHKライセンス窓口への通信はブロックしています。
本人確認の画面が表示された場合は、ユーザーが操作してください。

NHK ONE の旧 NHKプラス相当の動画は yt-dlp の対応対象外です。
NHKの番組保存、保護された動画の保存、ライブ配信の予約録画は本体に未実装です。
サイト変更によって保存できなくなることがあります。保存が認められた動画にお使いください。
保存形式は QuickTime 向けの MP4（H.264 / AAC）です。
対応する配信形式を優先して取得します。そのため選択した上限より低い画質になる場合があります。
対応済みの映像・音声は再圧縮せず、必要なトラックだけ FFmpeg で変換します。
変換が必要な場合は時間がかかり、再圧縮による画質の変化が生じることがあります。
音声のない動画は無音の MP4 として保存します。既存の MKV ファイルは変更しません。
更新前からアプリを開いていた場合は、終了して再度開くと新しい版になります。

再ビルド: zsh build.sh
このビルドは開発用のローカル署名です。配布用の公証はしていません。

このMacでのCDM部品の分離試験
local-components/WidevineCdm がある場合、build.sh はアプリのResourcesへコピーします。
Chromeのインストール先から実行時に探す処理はありません。
現在のローカル部品は、このMacで検証済みのGoogle CDMを未改変で複製したものです。
入手元とハッシュは local-components/provenance.json に記録しています。
アプリ内の部品を自作ホストから初期化できましたが、本体のNHK保存処理への接続は未実装です。
その後0.3.1で、アプリ自身のログイン情報と同梱部品を使う認証確認を接続しました。
「接続の準備を確認」は外部送信をせず、確認用番組の認証要求を生成して終了します。
「視聴認証を1回試す」は、NHKへの1回の要求を行い、視聴用の応答をCDMで処理します。
今回の1回は実行済みで成功しました。結果と実行済みの記録はアプリ再起動後も保持します。
実行済みの記録があれば再送を止めます。削除して再試行する操作はしないでください。
番組の映像・音声の取得・復号・MP4保存は、この認証テストには含まれません。
NHKの認証情報は子プロセスへの匿名パイプで渡し、コマンド引数やログには残しません。
このローカル試験は、Google CDMの配布許諾を確認したものではありません。
一般配布には提供・利用・配布条件の確認が必要です。公式案内:
https://developers.google.com/widevine/access
外部のffmpeg / ffprobe依存は残っています。
